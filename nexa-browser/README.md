# NexaBrowser — تطبيق متصفح Android أصلي

NexaBrowser هو تطبيق Android خفيف مبني بواجهة عربية/إنجليزية محلية، ومحرك **Android System WebView (Chromium)** للصفحات الفعلية. الواجهة لا تعتمد على CDN أو مكتبات JavaScript خارجية؛ وهي منفصلة عن جلسات WebView الأصلية.

## البناء والتشغيل

### بناء محلي

المتطلبات: JDK 17، Android SDK Platform 34، Android Build Tools، واتصال بمستودعات Gradle/Maven لتنزيل ZXing Core المستخدم في QR.

```bash
cd nexa-browser
./gradlew --no-daemon assembleRelease
```

الناتج: `app/build/outputs/apk/release/app-release.apk`.

### تنزيل APK من GitHub Actions

يدعم المشروع workflow باسم **Build NexaBrowser APK**. بعد دفع التغييرات إلى فرع جلسة Arena، يبدأ بناء APK تلقائيًا ويرفعه كـ Artifact. تشغيل workflow يدويًا ينشر كذلك إصدارًا باسم `nexa-v1.0.0` مع الملف `NexaBrowser.apk`.

نسخة CI موقعة بمفتاح تطوير لتسهيل التثبيت والاختبار؛ ليست توقيع متجر Google Play أو مفتاح تحديث إنتاجي. لا تُعد استخدام مفتاح تطوير عام لإصدار تجاري.

### ما يعمل فعليًا

- التنقل في مواقع HTTP/HTTPS عبر WebView النظام، فتح الروابط الواردة، شريط عنوان ومحركات Google/Bing/DuckDuckGo/Brave ومحركات HTTPS مخصصة.
- تبويبات عادية وخاصة، حفظ التبويبات محليًا، Grid/List، تثبيت وإغلاق بالسحب، واستعادة التبويبات المغلقة. بحد افتراضي خمسة WebViews نشطة؛ تُحرر الجلسات الأقدم لتقليل RAM، ويمكن تعطيل هذا السلوك من الإعدادات.
- بحث صوتي عبر واجهة Android، وماسح QR حقيقي يعمل محليًا بعد طلب إذن الكاميرا عند استخدامه.
- تنزيل الملفات إلى Android DownloadManager، مع التقدم والحالة والإلغاء وإعادة المحاولة والفتح والمشاركة والتصنيف.
- حجب نطاقات إعلانية ومتتبعات محددة محليًا، تنظيف بعض query parameters، قائمة استثناءات، وضبط Cookies الطرف الثالث.
- إشارات مرجعية ومجلدات وسجل محلي، مع استيراد/تصدير JSON.
- وضع قراءة يستخرج النص من المقالة الحالية ويحفظه نصيًا للقراءة بلا اتصال.
- خزنة كلمات مرور محلية اختيارية: AES-256-GCM بمفتاح Android Keystore، وPIN لا يقل عن 6 محارف مشتق بـ PBKDF2. التعبئة إلى الصفحة يدوية ولا تتم إلا بعد تأكيد المستخدم.
- Extensions مدمجة كـ Content Scripts محدودة داخل WebView، يمكن تثبيتها وإيقافها وإزالتها؛ يدعم المحرك Userscript يكتبه المستخدم.
- لقطات شاشة محفوظة محليًا، مشاركة الصفحة، البحث داخل الصفحة، موقع سطح المكتب، التكبير، النسخ، فتح خارجي وأدوات سجلات المطور.
- حالات تحميل/اتصال فارغة وواضحة، خلفيات متعددة، وضعا العربية RTL والإنجليزية LTR، وتصميم متجاوب للاتجاهين الطولي والعرضي.

## حدود المنصة — موضحة عمدًا في الواجهة

- **VPN:** خدمة `VpnService` معلنة كنقطة تكامل فقط. لا توجد خدمة أنفاق أو خوادم WireGuard/OpenVPN، ولا يتصل التطبيق أو يغيّر عنوان IP. اختيار المنطقة أو حفظ عنوان endpoint لا ينشئ اتصال VPN.
- **Sync:** لا يتضمن الإصدار خادمًا أو بروتوكول مزامنة/تسجيل دخول؛ البيانات لا تُرفع. إعداد عنوان الخادم مجرد إعداد محلي مستقبلي.
- **Extensions:** Android System WebView لا يدعم متجر Chrome أو حزم CRX وواجهات Chromium Extensions كاملة. الموجود إضافات مدمجة صغيرة تعمل كـ Content Scripts، ولا نزعم توافقًا عامًا مع إضافات Chromium.
- **الحجب والحماية:** قوائم Ad/Tracker محلية وثابتة ومحدودة. فحص العناوين اختياري ومحلي واستدلالي؛ لا توجد قاعدة سمعة مواقع أو حماية تصيد/برمجيات خبيثة سحابية.
- **التصفح الخاص:** لا يحفظ هذا الوضع السجل المحلي، ويعطّل DOM storage وذاكرة التخزين المؤقت ويحظر Cookies الطرف الثالث. مع ذلك لا يوفّر Android WebView ملف تعريف Cookies معزولًا هنا؛ قد تظل Cookies الطرف الأول مشتركة. تنزيل يبدأ من تبويب خاص يظل ظاهرًا في مدير التنزيلات ومجلد Android، لكن NexaBrowser لا يضيف Cookies محفوظة إلى طلب التنزيل الخاص.
- **التنزيلات:** Android DownloadManager لا يتيح لهذا التكامل الإيقاف المؤقت/الاستئناف؛ يمكن الإلغاء ثم إعادة المحاولة.
- **الترجمة وإشعارات المواقع:** لا يوجد مزود ترجمة أو API مدمج، وإشعارات الويب غير مفعلة في هذا الإصدار.
- **الأذونات:** الكاميرا والميكروفون لا يُطلبان إلا عند الضغط على ماسح QR أو البحث الصوتي. أذونات المواقع الأخرى لا تُمنح تلقائيًا.

## الخصوصية

لا يوجد تحليلات أو قياس استخدام أو مفاتيح API. طلبات البحث والمواقع تذهب فقط إلى الجهة التي يختارها المستخدم عند التصفح. كلمات المرور لا تحفظ في `localStorage` ولا تُرسل إلى خادم؛ إدارة كلمات المرور تتطلب تطبيق Android الأصلي وAndroid Keystore. بيانات المتصفح العامة محفوظة محليًا داخل مساحة التطبيق.

## التبعيات

- Android SDK / System WebView.
- [ZXing Core 3.5.3](https://github.com/zxing/zxing) لفك رموز QR محليًا (ترخيص Apache-2.0).
- لا توجد حزمة Play Services أو مكتبات تحليل/إعلانات.

# NexaBrowser v1.0.0

أول إصدار قابل للتثبيت من متصفح Android NexaBrowser.

### يتضمن
- واجهة عربية RTL وإنجليزية LTR بنمط Dark Premium.
- تصفح فعلي باستخدام Android System WebView، تبويبات Lazy/Hibernation، وسجل/إشارات محلية.
- QR scanner محلي، بحث صوتي عند الطلب، Android DownloadManager، Ad/Tracker blocking محلي، Reading Mode ولقطات شاشة.
- خزنة كلمات مرور اختيارية ومشفرة محليًا بـ AES-GCM داخل Android Keystore.

### حدود معلنة
لا يحتوي هذا الإصدار على خدمة VPN أو خادم Sync أو مزود ترجمة. إضافات المتصفح هي Content Scripts مدمجة وليست حزم Chrome CRX. تنزيلات Android لا تدعم pause/resume في هذا التكامل. انظر [README](README.md) للتفاصيل.

**التوقيع:** نسخة CI للاختبار موقعة بمفتاح تطوير؛ ليست إصدار متجر أو إعداد توقيع إنتاجي.
